# ComfyNode Sentinel — Workspace Engineering Rules

## 1. Architecture & Dual-Mode Runtime
- **Stack**: Next.js 15 (App Router, `output: 'standalone'`), React 19, TypeScript, Tailwind CSS v4, Vitest, and a Tauri v2 Rust desktop shell (`src-tauri/`).
- **Desktop Architecture**: In release builds, `src-tauri/src/lib.rs` spawns the bundled Next.js standalone server (`standalone-server/server.js`) on `127.0.0.1:<port>` and navigates the `main` webview to `http://127.0.0.1:<port>/`.
- **Dual-Mode Support**: UI features that invoke Tauri commands (`lib/tauri-bridge.ts`) must gracefully fall back to Next.js API routes when running in standalone web mode or if a Tauri plugin call fails.

## 2. Tauri v2 IPC, ACL & Tray Invariants
- **`Origin::Remote` on Localhost**: Tauri v2 treats `http://127.0.0.1:<port>/` and `http://localhost:<port>/` as `Origin::Remote` (not `Origin::Local`). `src-tauri/capabilities/default.json` must keep `"local": true` and `"remote": { "urls": ["http://127.0.0.1:*", "http://127.0.0.1:*/*", "http://localhost:*", "http://localhost:*/*"] }`.
- **AppManifest Registration**: Every custom `#[tauri::command]` in `src-tauri/src/lib.rs` must be listed in `src-tauri/build.rs` (`tauri_build::AppManifest::new().commands(&[...])`), granted via `"allow-<command-kebab-case>"` in `src-tauri/capabilities/default.json`, and have its generated `src-tauri/permissions/autogenerated/*.toml` committed.
- **Minimize-to-Tray Lifecycle**: `MinimizeToTrayState` defaults to `true` and must be guarded on both `WindowEvent::CloseRequested` and `RunEvent::ExitRequested` (preventing exit unless `ExplicitQuitState` is set or `code.is_some()`). Explicit tray `quit` must set `ExplicitQuitState` and terminate the `StandaloneServer` child process.

## 3. Build, CI/CD & Cross-Platform Invariants
- **Windows `@vercel/nft` `os.homedir()` Rule**: Never combine `os.homedir()` directly with `path.join(...)` in server-side code (`lib/server-fs.ts`, `app/api/**`). `@vercel/nft` statically evaluates it during `next build` into a wildcard glob over `C:\Users\runneradmin\**/*`, failing on Windows CI runners with `EPERM: scandir 'C:\Users\runneradmin\Application Data'`. Always resolve the home directory via `process.env.HOME || process.env.USERPROFILE` first (as in `getRuntimeHomeDir()`).
- **Cross-Platform `package-lock.json`**: Never overwrite `package-lock.json` from a single-OS `npm install` in a way that drops optional platform bindings (`@tauri-apps/cli-win32-x64-msvc`, `@next/swc-*`, `@tailwindcss/oxide-*`, `@img/sharp-*`, `lightningcss-*`).
- **`tauri-action` & `bun.lock`**: Because `bun.lock` is present in the repo, `.github/workflows/release.yml` must pass `tauriScript: npx tauri` to `tauri-apps/tauri-action@v0`.
- **GitHub Actions Node Runtime**: Use `actions/checkout@v7` and `actions/setup-node@v7` (native `node24`) in `.github/workflows/`.
- **GitLab CI Cache Limit**: In `.gitlab-ci.yml`, `cache:key:files` must contain at most **2** file paths.
- **ESLint Ignores**: `eslint.config.mjs` must ignore `.next/**`, `out/**`, `dist-web/**`, `src-tauri/**`, and `node_modules/**` so staged standalone/desktop artifacts are not linted.

## 4. ComfyUI Domain Safety Invariants
- **Atomic Node Toggling**: Enable/disable custom nodes strictly via directory rename (`<Folder>` ↔ `<Folder>.disabled`); never delete files or alter `.git` history.
- **Single-Worker FIFO Pip Queue**: Never run concurrent `pip install` commands against the same Python environment (`python_embeded` or `venv`).
- **Torch Shield**: Scan every `requirements.txt` for `torch`, `torchvision`, `torchaudio`, or `xformers` before executing `pip install`, pausing for explicit user resolution when matched.
- **Safe Deletion**: Move uninstalled nodes to the system Trash / `.sentinel_trash` quarantine rather than using destructive `rm -rf`.

## 5. Verification Before Completing Changes
- **Web / TypeScript**: `npx tsc --noEmit`, `npm run lint`, `npm test`, and `npm run build` (when build/bundling or server files change).
- **Rust / Tauri** (when `src-tauri/` changes): `cargo check --manifest-path src-tauri/Cargo.toml --all-targets`, `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`, and `cargo test --manifest-path src-tauri/Cargo.toml`.
