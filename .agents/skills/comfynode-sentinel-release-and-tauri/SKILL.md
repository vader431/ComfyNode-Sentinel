# ComfyNode Sentinel — Tauri IPC & Dual-Remote Release Runbook

## 1. Adding a New Tauri v2 Command
Because Tauri v2 loads the bundled Next.js standalone server from `http://127.0.0.1:<port>/` (treated as `Origin::Remote`), every new command requires all of the following steps:

1. **Implement the command in `src-tauri/src/lib.rs`**:
   - Annotate with `#[tauri::command]` (use `async` + `tokio::task::spawn_blocking` for blocking OS dialogs/I/O).
   - Register the function in `tauri::generate_handler![...]`.
2. **Expose it in `src-tauri/build.rs`**:
   - Add the exact snake_case command name to `tauri_build::AppManifest::new().commands(&[...])`.
3. **Generate autogenerated permission TOMLs**:
   - Run `cargo check --manifest-path src-tauri/Cargo.toml --all-targets` so `tauri-build` generates `src-tauri/permissions/autogenerated/<command>.toml`.
4. **Grant the permission in `src-tauri/capabilities/default.json`**:
   - Add `"allow-<command-kebab-case>"` to `"permissions"`.
   - Ensure `"local": true` and `"remote": { "urls": ["http://127.0.0.1:*", "http://127.0.0.1:*/*", "http://localhost:*", "http://localhost:*/*"] }` remain intact.
5. **Wire frontend + fallback in `lib/tauri-bridge.ts`**:
   - Call `invoke(...)` when `isTauriEnvironment()` is true, and provide an API route fallback (e.g., `/api/environment/pick`) when running in standalone web mode.

## 2. Cutting a Release (`vX.Y.Z`)

1. **Align version numbers**:
   - `package.json` (`"version"`)
   - `src-tauri/tauri.conf.json` (`"version"`)
   - `src-tauri/Cargo.toml` (`version = "..."`)
   - `CHANGELOG.md` (add `## [X.Y.Z]` section; `scripts/extract-release-notes.mjs` extracts this for GitHub/GitLab releases).
2. **Run full local verification**:
   ```powershell
   npx tsc --noEmit
   npm run lint
   npm test
   npm run build
   cargo check --manifest-path src-tauri/Cargo.toml --all-targets
   cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
   cargo test --manifest-path src-tauri/Cargo.toml
   ```
3. **Commit, tag, and push to both remotes (`origin` = GitHub, `gitlab` = GitLab)**:
   ```powershell
   git add <files>
   git commit -m "release: vX.Y.Z"
   git tag -a vX.Y.Z -m "Release vX.Y.Z"
   git push origin main
   git push origin refs/tags/vX.Y.Z
   git push gitlab main
   git push gitlab refs/tags/vX.Y.Z
   ```
4. **Monitor pipelines**:
   - GitHub Actions: `CI` and `Release Desktop Installers` (`.github/workflows/release.yml` creates a draft release, builds 4 Tauri targets using `tauriScript: npx tauri`, generates `SHA256SUMS.txt`, and publishes).
   - GitLab CI: `.gitlab-ci.yml` (`build:web`, `package:linux`, and `release:gitlab` publishing to the Generic Package Registry and GitLab Releases).
